# C6.2 Composer and channel header — Execution Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use doperpowers:subagent-driven-execution to implement this plan task-by-task. Deliverables use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give afleet's channel column a composer that sends, routes, escapes to the shell, queues, edits, suggests and picks — and a header whose menus act — with every write going through X5 and every displayed setting coming from an engine readback.

**Architecture:** Two `@MainActor @Observable` models per channel under `App/Composer/` and `App/Header/`, sharing one small `ChannelSurfaceState` so a restart can disable the field without owning the draft. Both read `LifecycleAPI` (X5) and the channel's `ChannelTimelineModel`/`ChannelContext`; neither holds a process or opens a file. The router UI renders C4's `RouterTable` and dispatches C4's `Routed`; the shell escape calls C2's `ShellEnvelope`; the queue chip reads C3's `Overlay.queue`.

**Tech Stack:** Swift 6.3.3 in language mode 6 with complete strict concurrency, SwiftUI and AppKit on macOS 26, XcodeGen 2.46.0, XCTest, `Tools/fake-claude` and the fixtures `control-shapes`, `rewind-turn`, `background-shell`, `plain-two-turn`.

**Status:** approved for execution, 2026-09-08. Q1 authorised (two call sites in `ChannelColumnView.swift`), Q2 accepted with a C4 corrective dispatched on `main`, Q3 yes — Task 9 stays. Item 13 amended: the request carries `last_seen_user_message_uuid` and both refusal strings trigger the fork fallback.

**Spec:** `docs/doperpowers/specs/2026-09-08-c6.2-composer.md` (leaf C6.2 of the composite `docs/doperpowers/specs/2026-09-07-c6-conversation-surface.md`; parent-pin `5e24f1a`). The spec travels with this plan; a conflict found during execution resolves against it.
